# 🛠️ AtelierPro Mobile

> **Solution mobile de gestion d’atelier destinée aux artisans nigériens 🇳🇪**

AtelierPro est une application mobile conçue pour aider les artisans et petits ateliers à organiser leur activité grâce à un outil simple, accessible et adapté aux réalités locales.

La solution permet de gérer les clients, commandes, paiements, informations métiers et suivi des travaux depuis un smartphone.

---

# 🎯 Vision du projet

Dans de nombreux ateliers artisanaux, la gestion quotidienne repose encore sur des cahiers papier, ce qui entraîne :

* perte d’informations clients ;
* difficulté à suivre les commandes ;
* manque de visibilité sur les paiements ;
* absence d’historique des travaux réalisés.

AtelierPro apporte une solution numérique adaptée aux artisans qui souhaitent mieux organiser leur activité.

---

# ✨ Fonctionnalités principales

## 👥 Gestion des clients

* Création et modification des fiches clients ;
* Historique des commandes ;
* Informations de contact ;
* Suivi de la relation client.

---

## 📦 Gestion des commandes

* Création de commandes ;

* Suivi des états :

  * En attente ;
  * En cours ;
  * Terminée ;
  * Annulée.

* Numérotation automatique des commandes ;

* Suivi des délais ;

* Historique des réalisations.

---

## 💰 Gestion des paiements

* Enregistrement des acomptes ;
* Suivi du reste à payer ;
* Historique financier des commandes ;
* Gestion adaptée au paiement en FCFA.

---

## 🧵 Gestion multi-métiers

AtelierPro est conçu pour différents types d’ateliers :

* Couture ;
* Menuiserie ;
* Mécanique ;
* Cordonnnerie ;
* Maçonnerie ;
* Bijouterie ;
* Coiffure ;
* Soudure ;
* Autres métiers artisanaux.

Chaque métier peut disposer de ses propres informations spécifiques.

---

## 📱 Expérience mobile adaptée

* Interface simple ;
* Support mode clair et sombre ;
* Optimisation pour smartphones Android ;
* Pensé pour les environnements avec une connexion limitée.
